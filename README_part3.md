# Part 3 · Cleaning and population analysis

Open the extracted `sis2` folder in VS Code. Run the commands in the terminal from that folder. On Windows with Python installed:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src/cleaner.py
.\.venv\Scripts\python.exe src/analysis.py
```

The archive includes `data/valid_data.csv` for a local demonstration. It was generated by running the team's validator on the bundled World Bank JSON snapshot. The Kafka producer and consumer were outside this verification run. For a full pipeline run, use the validated CSV generated by part 2 after Kafka consumption.

`src/cleaner.py` trims text, standardizes country codes, converts year and population to integers, drops incomplete and invalid rows, and keeps the first valid record for each country and year. Counts are written to `data/cleaning_report.json`. Pass `data/cleaned_data.csv` to part 4 for SQLite loading.

`src/analysis.py` calculates percentage change with NumPy, filters Kazakhstan observations for 2015–2024, computes descriptive statistics with GroupBy, and pivots observations into a year-by-country table. Tables, three PNG charts, findings, and the data dictionary are in `analysis/`.

For local analysis with a different CSV, pass `--input PATH` to the relevant script. If you run `cleaner.py` with `--output PATH`, pass the same path to `analysis.py --input PATH`.
